# Design Context — NeetCode Landing Page Variants

## Target Audience
Software engineers preparing for coding interviews at top tech companies (Google, Meta, Amazon, OpenAI, Anthropic). Age 22–35, highly technical, spend hours in IDEs and terminals. Value clarity, efficiency, and credibility.

## Use Cases
- Discover NeetCode as an interview prep platform
- Evaluate course offerings and structured learning paths
- Build trust via social proof (company logos, testimonials, stats)
- Convert to free practice or paid Pro subscription

## Brand Personality
Technical yet approachable. Confidence-building without arrogance. Developer-first aesthetic. The founder story humanizes the brand. Community-driven.

## Design Goal
5 maximally distinct landing page explorations to compare and pick a winner. Each variant should be **bold, memorable, and push a unique aesthetic direction** while preserving the same content structure and data.

## Variants
1. **Whiteboard & Marker** (route /2) — Light, hand-drawn marker aesthetic. DSA structures drawn as marker illustrations (arrays, trees, linked lists). Sticky notes, dashed borders, Caveat headings.
2. **Chalkboard** (route /3) — Dark matte green, chalk textures and dust. DSA as chalk drawings (hash maps, adjacency lists, queues). Kalam headings, pastel chalk palette.
3. **Cyberpunk / Retro-Futurism** (route /4) — Void black, neon glows, CRT scanlines, terminal/HUD aesthetic. JetBrains Mono, glitch animations, sharp corners.
4. **DSA Visual** (route /5) — GitHub-dark slate, interactive graph/tree node visualizations as structural design elements. BFS traversal animations, dot-grid background. Algorithm visualization color conventions.
5. **Neo Brutalism** (route /6) — Light cream base, 4px black borders, hard offset shadows, 0 border-radius. Space Grotesk 900 uppercase headings, high-saturation color blocks, slight element rotation.

## Tech Stack
- React Router v7 (file-system routing via flatRoutes)
- Tailwind CSS v4 (via @my-better-t-app/ui package)
- shadcn/ui components (Button, Card, etc.)
- Google Fonts loaded in root.tsx
- Each route is a self-contained page component
